1 Your brand — saved on this device, set it once

Rewrites your copy with real AI. Paste an Anthropic API key from console.anthropic.com (this is the developer console, not a Claude Pro subscription — it bills per use, usually a cent or two per listing). Stored only in this browser; never use it on a shared computer.

2 The listing
or paste the listing text

On the listing page: Ctrl/Cmd+A select all → Ctrl/Cmd+C copy → paste below. Price, beds, baths, cars & size fill in automatically. Pasting a copied photo adds it to your photos.

How do I get a listing in here?
  1. Easiest — link: open the listing on reiwa.com.au (or your agency's website), copy the address-bar link, paste it above, hit Import. Details and photos load automatically.
  2. Text: on any listing page: Ctrl/Cmd+A → Ctrl/Cmd+C → paste in the box above.
  3. Photos: drag photos from any webpage straight into the photo box below, or right-click a photo → Copy Image → paste here.

realestate.com.au & Domain block automated imports — but nearly every WA listing is also on reiwa.com.au, so import it from there. Link import uses public fetch services (the URL is shared with them; photos still stay in your browser).
